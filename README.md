# Flask Beginner Programs

This repository contains simple beginner-friendly Flask programs and mini projects created while learning Flask and Python web development.

The purpose of this repository is to practice:
- Flask basics
- Routing
- Templates using Jinja
- GET and POST methods
- Rendering HTML pages
- Basic backend development concepts

## Files Included

- app.py – Basic Flask application
- getpost.py – Example using GET and POST requests
- jinja.py – Jinja templating examples
- using_template.py – Working with HTML templates
- templates/ – HTML template files used in Flask

## Technologies Used

- Python
- Flask
- HTML
- Jinja2

## Goal

This repository is part of my learning journey in backend and web development using Flask.

More Flask mini projects and improvements will be added over time.
